# slides/ — HTML 簡報

依 `AGENTS.md` 3.4 產出。根據 `slides_outline/<slug>.md` 產出：

```text
slides/<slug>/
├── index.html      # 單一 HTML 簡報，直接用瀏覽器開啟
└── img/            # 從 assets/ 複製過來的圖片（不使用網路圖片）
```

## 基本規格（風格細節待討論後補上）

- 一頁對應逐頁內容的一個 `---` 區段，文字不得超出逐頁內容。
- **主題式結構**：封面 → 主頁（主題方塊，可點擊）→ 主題內容。每個 `<section>` 以 `data-topic` 標示所屬主題（`cover`、`home`、`01`…）。
  - ← → 只在同一主題內翻頁；主題結束回主頁。`H`／`Esc` 回主頁，右下角有 ‹ ⌂ › 按鈕。
  - 每頁右上角有「← 主頁」；頁尾顯示「主題名稱 · 頁次 / 總頁數」。
  - 主題頁底部「延伸閱讀」按鈕（`data-ref="R1"`）會跳到建議文獻中對應的卡片。
- 主頁分三列，每列 5 格：A 依類型、B 依族群推薦、C 行程與資料。實線格＝有內容；虛線格＋「預留」標籤＝預留主題頁；空白「＋」格＝之後新增主題的位置。
- 建議文獻是一個主題，每頁 6 張卡片（3 × 2），依類別分頁；標題連結在新分頁開啟；虛線「＋」卡為新文獻預留位置。
- 不做「wiki 還缺什麼」頁。

### 之後新增內容
- **新增咖啡廳**：在 HTML 最下方 `CAFES` 陣列加一筆（店名、風格、必點、時間、來源）；每頁 9 張，超過時複製一頁咖啡廳 `<section>` 並改 `data-cafes="18-27"`。
- **新增文獻**：在 `REFS` 加一筆，再把編號放進某個文獻頁的 `data-cards`（可取代 `slot`）。
- **新增主題**：把主頁的空白「＋」格換成 `<button class="tile" data-go="新id">`，並複製檔案最後的「新主題範本」`<section>`。
- **預留主題轉正**：文獻導入 wiki 後，把預留頁的 `.reserve-box` 換成內容版型，主頁格拿掉 `reserved` 與「預留」標籤。
- 操作：`F` 全螢幕，`S` 顯示講者備註。
- LaTeX：以 KaTeX 渲染 `$...$` 與 `$$...$$`（需要網路連線載入 KaTeX）。
- 支援列印 / 另存 PDF（一頁一張，依原始順序）。
- 本機預覽：`.claude/serve.ps1` 啟動 `http://localhost:8765/`（直接雙擊開啟時，部分瀏覽器可能擋圖片）。

## 風格設定（草案，樣張：`slides/_style_sample/index.html`）

方向：**文青手帳 × 日式極簡，參考無印風**（只取氛圍，不使用任何品牌名稱或標誌）。

| 項目 | 設定 |
|---|---|
| 比例 | 16:9（1600 × 900，等比縮放） |
| 底色 | 米白紙 `#F5F2EB`，內頁加淡淡的手帳點陣格 |
| 文字 | 墨色 `#34322E`、淡墨 `#6F6A61`、鉛筆灰 `#A39D92` |
| 點綴色 | 低彩度磚紅 `#8E3B32`（只用在數字、標記、手繪底線），牛皮紙 `#C8B796`（紙膠帶、章節編號） |
| 線條 | 只用 1px 細線；表格只有一條粗線（表頭）＋細線 |
| 字型 | 標題：霞鶩文楷 TC（手寫感）；內文：思源黑體 Noto Sans TC Light／Regular |
| 裝飾 | 手繪底線、紙膠帶、圓形印章，各頁最多一種 |
| 插圖 | `assets/` 吉祥物，放在角落當貼紙，不放在內文中間 |
| 動畫 | 只有換頁淡入（0.45 秒） |

### 版型

封面、章節、五格分類、店家卡片、表格、時間軸、公式（LaTeX）、建議文獻、結語。
