# slides_outline/ — 逐頁內容

依 `AGENTS.md` 3.4 產出。根據 `notes/<slug>.md` 寫成 `slides_outline/<slug>.md`，**一個檔案一份簡報**，以 `---` 分頁。

**鐵則**：只能使用 notes 裡已有的內容，不得新增事實。

## 每頁欄位

| 欄位 | 說明 |
|---|---|
| `## 第 N 頁：標題` | 頁面標題（投影片上顯示） |
| 主題 | 所屬主題編號（`—` 封面、`主頁`、`01`…）；第 2 頁固定為主頁（主題目錄） |
| 版型 | 封面 / 主頁 / 數字 / 五格分類 / 店家卡片 / 表格 / 時間軸 / 文獻卡片 |
| 延伸閱讀 | 選填，對應的建議文獻編號（例：R1、R5） |
| 重點 | 投影片上出現的文字，3–5 點為宜（可含 LaTeX） |
| 講者備註 | 口頭補充，不顯示在投影片上 |
| 配圖 | 只能用 `assets/` 或 `raw/assets/` 內的圖片；沒有就寫「無」 |
| 來源 | 對應的 `[[檔名]]` |

## 範本

````markdown
---
title: 員林甜點半日遊
slug: 20261111_員林甜點半日遊
from_note: notes/20261111_員林甜點半日遊.md

- 配圖：無
- 來源：notes/20261111_員林甜點半日遊.md
````
