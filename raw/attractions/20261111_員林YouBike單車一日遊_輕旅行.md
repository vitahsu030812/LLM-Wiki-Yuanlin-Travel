# 員林 YouBike 單車一日遊（輕旅行，2018）

## 景點
- 員林服務中心｜民權街55號｜週二至六 09:00–18:00（12–13 休息）。
- 警察故事館｜三民街14號｜09:00–11:30、14:00–16:30｜日治時期官舍改建，2014-12-19 開館，彰化縣警察局管理。
- 員林公園｜三民街1號｜老字號公園。
- 興賢書院｜三民街1號（公園內）｜04-8342571｜07:00–19:00｜1807 年文昌祠起源，921 損壞後修復。
- 琉璃仙境｜08:30–17:30｜門票 50 元（2018）。
- 圓林園｜員林大道四段與大勇街口｜2018 新公園，滯洪兼休閒，草坡適合野餐，暱稱「員林秋紅谷」。
- 龍燈公園｜莒光路734號｜2012 台灣燈會主燈「龍翔霞蔚」（約 20 公尺），2013-01-26 開放；旁邊高架橋下有 3D 彩繪。
- 靜修國小 靜修鐵道文化園區｜靜修路74號｜僅週末開放，上課時間勿入｜2017 設立的鐵道主題彩繪校園。
- B12 文創特區｜新生路320號｜04-8318111｜10:30–21:00｜貨櫃文創園區、3D 彩繪；旁有戰後鐵路穀倉（員林立庫）。
- 打石巷｜黎明巷51號一帶｜員林最早的街道，昔日打石、打鐵聚落。
- KOKOMO 私房惑櫃｜條和街142號｜11:00–23:00｜每人低消 200 元（2018）。

## 小吃
- 姊妹飯糰｜育英路109號｜06:00–12:00｜份量大、餡料多。
- 火雲掌伯豆標｜員水路二段｜06:00–11:00、13:30–17:00｜一個約 5 元（2018）。
- 莫忘鯛魚燒｜成功路51號｜13:00–19:00（2018）。
- 新生路圓仔冰｜員鹿路16號｜04-8399208｜08:00–22:00｜古早味八寶冰、Q 圓仔。
- 番薯市八寶圓仔冰｜光明街216號｜04-8336245｜12:00–23:00｜花生冰、燒麻糬，常排隊。

## 交通
- 2018 年員林有 19 個 YouBike 站（含員林火車站前廣場、第一市場、員林轉運站等）；火車站出口正對面即有站點。
- 單車路線：火車站 → 警察故事館 → 員林公園、興賢書院 → 琉璃仙境 → 豆標 → KOKOMO → 莫忘鯛魚燒 → 圓林園 → 龍燈公園 → 靜修國小 → B12 → 圓仔冰 → 第一市場 → 打石巷 → 火車站。
